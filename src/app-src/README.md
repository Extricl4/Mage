# Mage

Privat FODMAP-skanner for norske butikker. Skann en strekkode, og appen viser varen og hver ingrediens i grønt, gult eller rødt (lav, middels, høy FODMAP). Grått betyr at appen ikke vet nok.

- Data om varer: [Open Food Facts](https://no.openfoodfacts.org) (Kassalapp som valgfri reserve)
- FODMAP-vurderinger: Haukeland universitetssjukehus (NKFM) og Monash University
- Strekkodeleser: [ZXing](https://github.com/zxing-js/library) (Apache 2.0)

Generelle råd – ikke medisinsk rådgivning. Appen lagrer historikk og innstillinger bare på telefonen.

Bygget og vedlikeholdt med Claude. Ikke rediger `index.html` for hånd – den genereres.
